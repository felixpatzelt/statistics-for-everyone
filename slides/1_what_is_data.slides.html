  • The contents of books
  • The temperature shown on a thermometer

Examples for Data in Electronic data Processing¶

  • In modern computers, everything is binary

    • e.g. 101010

  • Data types make a datum easier to use

    • Integers: 42
    • Floating point numbers: 3.14
    • Strings: "This is a string!"

We can organise data¶

  • Lists (Arrays), e.g. [1,2,3]
  • Tables / DataFrames,
    i.e. values organised in columns / rows
  • Databases containing tables
  • An .mp4 file containing video and audio 🎬🍿


Visicalc, the first spreatsheed, on an Apple II

"Structured data"¶

  • Rigid schema
  • E.g. in an SQL table each column has a
    • Unique name
    • Data type
    • …and hopefully also semantic meaning

"Unstructured data"¶

  • No single predefined format (schema) for its contents
    • A collection of emails
    • A collection of images
  • Often lives in a data lake or document store (like s3, mongoDB, …)

How and Why is Data used?¶


The Ishango bone, ~20000 BCE

Recording symbols, marks, and images might be as old as humanity

  • Help to remember something for later
  • Pass information to others
  • As a tool for complex resoning or calculations

Descriptive Statistic(s)¶

  • Making a summary ("statistic") that quantitatively describes data

    • The number of participants in a survey 💯
    • The average height of an adult in a certain region 📏
    • The income distribution in a society 💰

  • Using and analysing such summaries.
